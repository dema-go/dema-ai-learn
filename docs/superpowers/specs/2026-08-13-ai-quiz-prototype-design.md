# AI 闯关学习小程序 — UI 原型设计规范

> 版本 v1.0 ｜ 2026-08-13
> 依据：`需求分析.md`、`技术方案.md`、`竞品调研资料.md`
> 风格基调：《漫画阿衰》意境 × 暖色手账笔记本风
> 交付物：三个高保真 HTML 原型 + 一份共享样式

---

## 1. 产品与设计目标

**一句话定位**：微信里最快的「可溯源读后自测」——粘贴文本/链接 → AI 严格只依据原文出 5–7 题 → 3 分钟闯关 → 每题回到原文 → 次日只复测错题。

**设计要服务的核心动作**：输入成功 → 开始 → 完成 → 下一次有效学习。
所有页面只服务这条主线，不为验证外的功能让步。

---

## 2. 风格哲学

> **「一本被涂鸦批注的暖黄课堂笔记本，主角是个陪你一起犯错的笨学生。」**

- **外衣**：阿衰式手绘幽默——暖纸底、墨色手绘线、涂鸦批注、对话气泡、原创吉祥物「小衰」。
- **内核**：严肃可信——题目 / 原文依据 / 结果数据 / AI 标识区一律白底干净卡片，不加漫画装饰。
- **铁律**：幽默只出现在「装饰位」（引导、反馈、空状态、角色台词、CTA），**绝不污染内容呈现区**。

---

## 3. 视觉系统

### 3.1 配色（暖色手账笔记本风）

| 角色 | 色值 | 用途 |
|---|---|---|
| 纸张底 Paper | `#FBF5E9` | 全局背景（暖米黄） |
| 卡片白 Card | `#FFFDF7` | 内容卡片底 |
| 墨棕 Ink | `#3D2E1F` | 主文字 + 手绘线条（不用纯黑） |
| 墨灰 InkSoft | `#7A6A52` | 次要文字、说明 |
| 水彩绿 Moss | `#6BA368` | 答对、通过、✓ 盖章 |
| 水彩红 Tomato | `#E06562` | 答错、纠错、✗ 盖章 |
| 暖橙 Amber | `#E8954C` | 主 CTA、进度、星标、重点 |
| 靛蓝 Indigo | `#5B7EA8` | 原文依据链接、可点元素 |
| 荧光黄 Highlighter | `#F2D96E` | 涂鸦高亮批注（原文划重点） |

### 3.2 字体

- **标题 / 角色台词**：手写感（霞鹜文楷 / 系统楷体 fallback）→ 手账气质
- **正文 / 题目 / 数据**：干净无衬线（PingFang SC / 思源黑体）→ 保证可读
- **数字 / 计时**：粗黑体强调

### 3.3 漫画元素库（克制点缀）

| 元素 | 出现位置 | 手法 |
|---|---|---|
| 对话气泡 | 吉祥物台词、引导、空状态 | 圆角云朵/椭圆 SVG |
| 手绘描边 | 卡片边框 | 微不规则圆角 + 实线/虚线 |
| 涂鸦批注 | 重点、原文高亮、错题 | 荧光笔、手画下划线、圈圈、星标、箭头 |
| 纸张质感 | 页面背景、卡片 | 极淡纸纹、便签贴纸、和纸胶带（顶部斜胶带） |
| 漫画符号 | 反馈、进度 | ✓/✗ 水彩盖章、晕眩圈、忙碌小线条、进度小印章 |
| AI 小印章 | 题目/解析/结果角标 | 圆角章「AI · 依据材料生成」 |

**节制原则**：题目区、原文依据区、结果数据区严禁漫画装饰。

### 3.4 组件视觉语言

- **主按钮**：墨棕描边圆角 + 暖橙填充 + 轻「贴纸」投影
- **选项卡**：白底墨棕描边；选中加粗描边；答对盖绿章、答错盖红章并划掉错误项
- **进度条**：一排**小印章**（已答=盖章，未答=空格），不用渐变条
- **原文依据**：报纸式引用块 + 荧光黄高亮 `source_span` + 靛蓝「回原文」链接
- **AI 标识**：右下角小印章式角标，统一文案「AI 依据你的材料生成，可能有误」

## 4. 吉祥物设定（原创，不挪用阿衰版权形象）

- **名字**：小衰
- **形象**：蘑菇头、Q 版、圆眼镜、校服，表情夸张
- **定位**：**和你一样的笨学生，不是聪明老师**。陪你学，答错它先自嘲「哎呀我又错了」——降低用户挫败感
- **出现**：首次引导、生成等待（趴桌/奋笔）、答对（欢呼）、答错（捂脸）、空状态、结果页（举成绩单）
- **原型实现**：占位简笔画 SVG + 表情 + 文字标注「吉祥物位」

## 5. 原型文件结构

```
prototypes/
├── styles.css                 # 共享设计系统（token + 组件类）
├── core-flow.html             # 核心业务流程（11 屏）
├── extended-features.html     # 扩展功能（9 屏）
└── states-compliance.html     # 状态/空状态/合规（9 屏）
```

每个 HTML：手机屏 mockup（375px 宽）× 一行三列 × 响应式（窄屏自动折行）。

## 6. 页面规格清单

### 6.1 core-flow.html（核心业务流程）
1. 启动 / 静默登录 loading
2. 首次引导（≤1 屏，小衰欢迎）
3. 首页（最近闯关 + 错题复测入口 + 开始学习 CTA + 今日额度）
4. 内容输入页（粘贴文本 / 网页链接 Tab，8000 字计数，隐私提示）
5. 正文预览 / 裁剪页（URL 抽取后预览）
6. 生成等待页（轮询进度文案，小衰忙碌）
7. 答题页（印章进度，题干，选项，AI 标识）
8. 单题反馈态（绿/红章 + 知识讲解 + 原文依据 + 纠错入口）
9. 结果页（正确率 + 用时 + 错题列表 + 结果卡 + 复测/分享 CTA）
10. 结果卡分享页（自愿分享，无诱导）
11. 错题复测答题页（复用答题页，标注「错题复测」）

### 6.2 extended-features.html（扩展功能，标注 P0/P1）
1. 次日订阅召回落地（P0）
2. 间隔复习日历（P0）
3. 题量与难度选择（P0）
4. 知识总结与复盘报告（P1）
5. 学习数据后台（P1）
6. 挑战好友结果卡（P1）
7. 付费额度 / 会员（P0）
8. 文档解析入口 beta（P0）
9. 分享落地页（被分享者视角）

### 6.3 states-compliance.html（状态 / 空状态 / 合规）
1. 首页空状态
2. 无错题空状态
3. 生成失败 / 超时重试
4. URL 抽取失败 / 遇登录墙
5. 内容安全未通过
6. 内容过短 / 为空
7. 一键纠错弹层（无依据 / 答案错 / 有歧义 / 太简单）
8. AI 标识规范（四处位置）
9. 额度用尽 + 隐私指引 / 内容删除入口

---

## 7. 合规与质量在 UI 上的落点

- **AI 标识**：题目、解析、结果页、分享卡四处的右下角统一小印章
- **一键纠错**：每题反馈态可唤起纠错弹层，四类原因
- **内容安全**：输入态、生成态的安全未通过兜底页
- **隐私**：输入页隐私小提示 + 独立隐私指引 / 内容删除入口
- **分享**：结果卡分享全流程自愿，无「分享解锁」诱导

---

## 8. 实现约定

- 纯 HTML + 内联/共享 CSS，无外部依赖
- 手机屏宽 375px，CSS Grid 一行三列，`auto-fit` 响应式
- 吉祥物用占位 SVG 简笔画 + 「吉祥物位」标注
- 三个 HTML 共享 `styles.css`
